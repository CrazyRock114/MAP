# MAP 数学自适应测试平台

上海民办双语学校 5-6 年级数学模拟题平台 (NWEA MAP Growth 风格)。

## 功能

- **1000 道双语题目** (英文题干 + 中文解答 + 双语关键词)
- **12 个年级** (G1-G12)，覆盖 5 大数学领域
- **3 种测试模式**:
  - 练习模式 (按知识点分类)
  - 自适应测试 (15 题, 估算 RIT 水平, 最高到 Level 5)
  - 错题回顾
- **错题收集** (自动记录答错的题)
- **本地存储** (localStorage, 零数据上传, 隐私安全)

## 技术栈

- 纯静态网站 (HTML/CSS/JS)
- 无后端，无数据库
- 兼容所有现代浏览器 (桌面/平板/手机)
- 部署到 Vercel / GitHub Pages / 任何静态托管

## 本地开发

```bash
# 方法 1: 直接打开 index.html
open index.html

# 方法 2: 用 npx serve
npm start
# 然后访问 http://localhost:3000
```

## 难度分级

| Level | RIT 范围 | 适用年级 |
|---|---|---|
| 1 | 180-195 | 1-2 年级 |
| 2 | 195-210 | 2-3 年级 |
| 3 | 210-220 | 3-4 年级 |
| 4 | 220-230 | 4-5 年级 |
| 5 | 230+ (MAP 最高) | 5-6 年级 + AMC 8 |
| 6 | 240+ (Pre-Calc) | 高中拓展 (仅练习模式) |

## 数据说明

- 所有题目**自编**，参考美国 CCSS 5-6 年级标准 + NWEA MAP 风格
- 不使用任何 NWEA 官方真题
- 答案与解释经过人工校验
- 适配学校：协和系、平和、世外、星河湾、包玉刚等

## 隐私

- **零数据上传** — 所有进度存储在浏览器 localStorage
- 不收集任何用户信息
- 关闭浏览器不影响数据（除非清除浏览器缓存）
